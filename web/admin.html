Welcome a display.

Generate a one-time code here, then enter it on the display within ten minutes. Only generate a code while you are pairing a display you control. Treat the code as a password until it expires; generating a new code invalidates the previous one. A paired display stays active while it keeps checking in; seven days offline requires pairing again. Revoked displays must pair again. A copied browser credential can impersonate its display.
